# Phase 2 Weekly Template — Push/Pull/Legs x2

Read [phase-2-overview.md](phase-2-overview.md) first for how the rep
ranges and progression actually work. This week repeats indefinitely;
insert a deload week (2 sets instead of 3, weights held flat) every 5–6
weeks.

Warm up 5–8 minutes before every session (see
[warmup-cooldown.md](warmup-cooldown.md)), plus 1–2 light warm-up sets of
the first exercise before your working sets. Cooldown/stretch 5 minutes
after.

## Day 1 — Push A
- Dumbbell floor press: 3 x 8–12
- Standing/seated dumbbell shoulder press: 3 x 8–12
- Push-ups (feet elevated on a step if bodyweight has gotten easy): 3 x 10–15
- Lateral raises: 3 x 12–15
- Overhead dumbbell triceps extension: 3 x 10–15
- Plank: 3 x 30–45s

## Day 2 — Pull A
- Dumbbell bent-over row (both arms): 3 x 8–12
- Single-arm dumbbell row: 3 x 10–12 per side
- Dumbbell Romanian deadlift: 3 x 8–12
- Reverse fly (bent over, rear delts/upper back): 3 x 12–15
- Dumbbell bicep curl: 3 x 10–15
- Dead bug: 3 x 10 per side

## Day 3 — Legs A
- Goblet squat: 3 x 10–15
- Weighted step-ups: 3 x 10–12 per leg
- Dumbbell Romanian deadlift (lighter than Pull A if same day type, or
  skip if legs are already fatigued from Pull A the day before): 2 x 10–12
- Weighted walking lunges: 3 x 10 per leg
- Calf raises (off a step edge): 3 x 15–20
- Flutter kicks: 3 x 20

## Day 4 — Push B
- Standing/seated dumbbell shoulder press: 3 x 8–12
- Dumbbell floor press or push-ups: 3 x 10–15
- Arnold press or lateral raise: 3 x 12–15
- Close-grip push-ups or triceps kickbacks: 3 x 10–15
- Front raise: 2 x 12–15
- Side plank: 2 x 30s per side

## Day 5 — Pull B
- Single-arm dumbbell row: 3 x 10–12 per side
- Renegade row (plank position, alternating row each arm): 3 x 8–10 per side
- Reverse fly: 3 x 12–15
- Hammer curl: 3 x 10–15
- Superman / back extension: 3 x 12–15
- Glute bridge: 3 x 15

## Day 6 — Legs B
- Bulgarian split squat (rear foot elevated on the step): 3 x 8–12 per leg
- Weighted step-ups: 3 x 10–12 per leg
- Dumbbell Romanian deadlift: 3 x 10–12
- Single-leg glute bridge: 3 x 12 per leg
- Calf raises: 3 x 15–20
- Plank: 3 x 30–45s

## Day 7 — Rest
Full rest. Optional easy 15–20 min walk or bike spin, foam rolling.

## Optional cardio add-on
1–2x/week, tack a 15–20 minute easy-to-moderate bike spin onto the end of
a Push or Pull day (not Legs, not the rest day) — see the "Where cardio
fits" section in phase-2-overview.md.
