# Training Log Template

Copy this table for each session (or keep a running log per exercise).
Double progression only works if you can see last session's numbers —
write down weight x reps for every set, every time.

## Session log

Notes column is for things like "form broke on last rep," "knee felt off,"
"felt strong today" — context that explains why a number went up, down, or
stayed flat.

When all three sets hit the top of the target rep range with clean form,
that's your cue to move up in weight next session (see the double
progression rules in [phase-2-overview.md](phase-2-overview.md)).

## Deload / bodyweight check-in (every 5–6 weeks)

| Date | Push-up max (strict) | Row weight x 10 reps | Plank hold | Notes |
|---|---|---|---|---|
| | | | | |

Use this to confirm the trend is actually upward over months, not just
week to week — muscle growth is slow enough that weekly numbers can look
flat even when the multi-month trend is solid.
